API REFERENCE SUMMARY
================================================================================

Methods:

  client.get_historical_data(symbol, timeframe, start, end, ...)
    → Get OHLCV candles for a symbol
    
  client.get_quant_features(symbol, timeframe, start, end, limit)
    → Get AI-ready technical indicators
    
  client.get_data_quality(symbol, days)
    → Get data quality report
    
  client.get_status()
    → Get API status and metrics
    
  client.get_symbols()
    → List available symbols
    
  client.health_check()
    → Check if API is healthy

Timeframes: 5m, 15m, 30m, 1h, 4h, 1d, 1w

Data Types: Candle, Feature (typed dataclasses)

Exceptions: ValidationError, AuthenticationError, RateLimitError,
            APIConnectionError, APIError

Features:
  • Automatic retry (3 attempts with backoff)
  • Connection pooling (10 concurrent)
  • Parameter validation
  • Response validation
  • Context manager support
  • Type hints throughout
  • Structured logging
